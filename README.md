This repository contains the genome-scale metabolic model iYH2021 for Chlamydomonas reinhardtii CC-4414, a light-tolerant natural isolate, together with all data and code supporting its reconstruction and analysis. The model was built using a template-based approach from iCre1355, gap-filled with CarveMe-derived candidate reactions, and integrated with condition-specific (high-light/low-light) proteomics data using the iMAT algorithm to predict metabolic flux redistribution under light stress. This repository accompanies the manuscript "Integrative Proteomics and Genome-Scale Modeling Elucidate Metabolic Flux Shifts in Chlamydomonas reinhardtii CC-4414 under Light Stress" and is provided to ensure full reproducibility of the reconstruction pipeline and downstream flux analyses.
